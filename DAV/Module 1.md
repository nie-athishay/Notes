# 1. Introduction to Data Analytics

### Definition

**Data Analytics** is the process of **collecting, cleaning, analyzing, and interpreting data** to find useful information and support better decision-making.

### Simple definition to remember

> **Data Analytics = Looking at data to understand what is happening and make better decisions.**

### Example – Supermarket

Suppose a supermarket has sales data for one year.

Using Data Analytics, we can find:

* Which product sells the most?
* Which month has the highest sales?
* Which products are not selling?
* Which customers buy more?
* How much stock should be purchased?

So, data analytics converts **raw data into useful information and insights**. 

---

# 2. Data vs Information vs Insight

This is an **important concept**.

### 1. Data

Data means **raw facts and values** collected from different sources.

Example:

`85, 72, 91, 65, 55, 88, 92`

These numbers alone do not tell us much.

### 2. Information

When data is **organized and processed**, it becomes information.

Example:

> Average attendance = 78%

Now the data has meaning.

### 3. Insight

An insight is a **useful conclusion obtained from analyzing information**.

Example:

> Students whose attendance is below 70% are more likely to have difficulty completing laboratory work.

This insight can help the college take action.

### Easy way to remember

> **Data = What we have**
> **Information = What the data tells us**
> **Insight = What we understand from it**

### Flow

**Data → Analysis → Information → Insight → Decision**

# 8. Types of Data Analytics ⭐⭐⭐

This is a **very important exam topic**.

Remember these four questions:

| Type             | Main Question             |
| ---------------- | ------------------------- |
| **Descriptive**  | What happened?            |
| **Diagnostic**   | Why did it happen?        |
| **Predictive**   | What is likely to happen? |
| **Prescriptive** | What should we do?        |

### Easy memory trick:

> **What → Why → What next → What to do**

---

## 8.1 Descriptive Analytics

### Definition

Descriptive Analytics summarizes past and present data to tell us **what happened**.

### Main question

> **What happened?**

### Example

Restaurant sales:

* January → ₹50,000
* February → ₹60,000
* March → ₹45,000
* April → ₹70,000

We can say:

> March had the lowest sales and April had the highest sales.

This is descriptive analytics.

### Examples of questions

* How many products were sold?
* What was the total revenue?
* How many students passed?
* How many customers visited the website?
* What were the sales last month?

---

# 8.2 Diagnostic Analytics

### Definition

Diagnostic Analytics tries to find **why something happened**.

### Main question

> **Why did it happen?**

### Example

We know:

> March had the lowest sales.

Now we investigate why.

Possible reasons:

* Heavy rain
* Fewer customers
* Popular food item unavailable
* Fewer promotional offers

Finding these reasons is **Diagnostic Analytics**.

### Easy difference

**Descriptive:** March sales were low.

**Diagnostic:** Sales were low because of heavy rain and fewer customers. 

---

# 8.3 Predictive Analytics

### Definition

Predictive Analytics uses **past and current data to predict what is likely to happen in the future**.

### Main question

> **What is likely to happen?**

### Example

A restaurant notices that during summer:

> Cold drinks and ice creams sell more.

So it predicts:

> Cold drink sales are likely to increase next month.

Important:

Prediction does **not guarantee** that something will happen. It means it is **likely to happen based on past data**.

### Student example

Using:

* Attendance
* Assignment marks
* Internal marks
* Previous exam performance

The college may predict that students with low attendance and low internal marks may have a higher risk of failing.

---

# 8.4 Prescriptive Analytics

### Definition

Prescriptive Analytics recommends **what action should be taken**.

### Main question

> **What should we do?**

### Example

Predictive Analytics says:

> Cold drink sales are likely to increase next month.

Prescriptive Analytics may recommend:

* Order more cold drinks
* Keep extra stock
* Give discounts
* Create combo offers
* Increase advertising

### Remember

**Descriptive → What happened?**

**Diagnostic → Why happened?**

**Predictive → What may happen?**

**Prescriptive → What should we do?**

# 9. Data Analytics Lifecycle ⭐⭐⭐

The PPT explains the lifecycle through these stages:

1. Define the Problem Statement
2. Collect the Data
3. Prepare the Data
4. Plan the Model
5. Build the Model
6. Visualize the Data
7. Interpret the Insights
8. Operationalize

---

## 1. Define the Problem Statement

First, clearly understand the problem.

Ask:

> **What do we want to find out from the data?**

Example:

A college wants to know:

> Why are some students getting low marks?

Problem statement:

> Identify factors affecting students' academic performance.

---

## 2. Collect the Data

Collect the required data.

Sources include:

* College databases
* Surveys
* Excel files
* Websites
* Sensors
* Applications
* Social media

Example student data:

| Student | Attendance | Study Hours | Assignment Marks | Exam Marks |
| ------- | ---------: | ----------: | ---------------: | ---------: |
| A       |        90% |           5 |               85 |         88 |
| B       |        60% |           2 |               60 |         55 |
| C       |        80% |           4 |               75 |         78 |

---

## 3. Prepare the Data

Collected data may contain:

* Missing values
* Duplicate records
* Incorrect values
* Different formats
* Unnecessary data

Therefore, data must be cleaned and prepared.

Example:

`90%`

and

`90 percent`

should be converted into a common format.

### Remember

> **Prepare = Clean the data and make it ready for analysis.**

---

## 4. Plan the Model

Decide:

* Which variables/features are important?
* Which analytical method should be used?
* Which model is suitable?
* What are we trying to predict/classify?

Example:

To predict whether a student will pass or fail, possible models include:

* Decision Tree
* Logistic Regression
* Random Forest

### Remember

> **Plan Model = Decide what method/model we should use.**

---

## 5. Build the Model

Apply the selected model to the data.

Example:

**Attendance + Study Hours + Assignment Marks**

↓

**ML Model**

↓

**Pass / Fail**

The model learns patterns from available data.

---

## 6. Visualize the Data

Results are represented using graphs and charts.

Examples:

* Bar chart
* Histogram
* Pie chart
* Scatter plot
* Box plot
* Line chart

Example:

A graph showing **Attendance vs Exam Marks** may help us see that students with higher attendance generally have higher marks.

### Remember

> **Visualization = Convert data/results into graphs so humans can understand them easily.**

---

## 7. Interpret the Insights

Now ask:

> **What does the result actually mean?**

Example:

Analysis shows:

> Students with attendance above 80% generally score higher.

This is an insight.

---

## 8. Operationalize

Put the analysis/model into practical use.

Example:

**Attendance < 60%**

↓

System identifies student

↓

Teacher receives notification

↓

Counselling/support provided

### Remember

> **Operationalize = Take the analytics/model into the real world and use it for decision-making.**

# 10. Types of Data ⭐⭐⭐

The PPT discusses four important types.

Structured data is organized in a **fixed format**, usually in rows and columns.

Example:

| Student ID | Name  | Age | Marks |
| ---------- | ----- | --: | ----: |
| 101        | Ravi  |  20 |    85 |
| 102        | Priya |  21 |    90 |
| 103        | Arun  |  20 |    78 |

### Examples

* Excel tables
* SQL databases
* Student records
* Bank transaction tables
* Employee records

### Easy definition

> **Structured data = Data organized in rows and columns.**

---

# 11. Semi-Structured Data

Semi-structured data does not follow a strict table format but has some organization using:

* Tags
* Keys
* Metadata

### Examples

* JSON
* XML
* HTML

Example JSON:

```text
{
   "name": "Ravi",
   "age": 20,
   "marks": 85
}
```

It does not have rows and columns like Excel, but we can still identify:

* name → Ravi
* age → 20
* marks → 85

### Definition

> **Semi-structured data = Data with some organization, but not a fixed tabular structure.** 

---

# 12. Unstructured Data

### Examples

* Images
* Videos
* Audio
* Emails
* Social media posts
* PDF documents
* Text documents

Example:

### Definition

> **Unstructured data = Data that does not have a predefined structure.**
